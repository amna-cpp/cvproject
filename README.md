# FaceShield Analytics

FaceShield Analytics is a computer vision portfolio project that studies how augmented-reality style face filters affect face-recognition systems. It reproduces the core evaluation idea from Ozturk et al. 2025, then extends it with a mitigation layer and a polished Gradio dashboard for interactive verification experiments.

## Why It Matters

Face filters are no longer just playful overlays. They can smooth skin, reshape faces, alter eye regions, and shift color distributions in ways that change biometric embeddings. This project turns that concern into a practical end-to-end system:

- prepares LFW verification pairs,
- applies six programmatic AR-style filter categories,
- extracts face embeddings,
- measures recognition degradation with accuracy, FMR, FNMR, and DET curves,
- compares baseline and improved recognition paths,
- applies correction strategies to recover filtered-face performance,
- serves the workflow in an interactive demo dashboard.

## Reference Paper

This implementation is inspired by:

**A Comprehensive Evaluation Framework for the Study of the Effects of Facial Filters on Face Recognition Accuracy**  
Kagan Ozturk, Louisa Conwill, Jacob Gutierrez, Kevin Bowyer, Walter J. Scheirer, 2025  
https://arxiv.org/abs/2507.17729

The paper evaluates real AR filters from Instagram, Snapchat, Meitu, and Pitu on FRGC images. This course prototype uses the public Labeled Faces in the Wild benchmark and programmatic filter simulations so the pipeline is reproducible without private app automation or restricted datasets.

## System Highlights

- **Dataset pipeline:** builds genuine and impostor verification pairs from LFW.
- **Filter simulation:** blur, brightness, skin smoothing, eye enlargement, face slimming, and warm color tone.
- **Recognition backbones:** ArcFace baseline plus an improved-path backend where available.
- **Metrics:** cosine similarity, threshold search, accuracy, FNMR at fixed FMR, DET CSVs, and comparison plots.
- **Mitigation:** mean-shift correction and Ridge-regression embedding correction.
- **Demo:** Gradio dashboard with upload/webcam intake, filter controls, mitigation controls, KPI cards, charts, and verification output.

## Repository Hygiene

The public repository intentionally excludes large or generated artifacts:

- LFW images and generated filtered images,
- DeepFace model weights,
- embedding `.npy` files,
- local cache folders,
- generated presentation/report binaries.

Small metrics, plots, and source scripts can be regenerated by running the pipeline.

## Setup

```bash
pip install -r requirements.txt
```

If you want to reproduce the full experiment, download or place the LFW dataset locally first. The setup script searches common local locations under `~/Downloads`.

## Run Pipeline

```bash
python src/07_run_pipeline.py --subset 300 --models arcface
python src/07_run_pipeline.py --upgrade-only --subset 300
```

Useful individual stages:

```bash
python src/01_setup_dataset.py --subset 300
python src/02_apply_filters.py --subset 300 --workers 4
python src/04_extract_embeddings.py --models arcface --subset 300
python src/05_evaluate_recognition.py --backbone arcface
python src/06b_mitigation_linear.py --backbone both
python src/08_compare_models.py
```

## Launch Demo

```bash
python app/app.py
```

The Gradio app opens locally at:

```text
http://127.0.0.1:7860
```

## Results Snapshot

The submitted experiment used:

- 300 genuine pairs and 300 impostor pairs,
- 807 unique LFW images,
- 6 simulated AR filter categories,
- 4,842 generated filtered images,
- baseline and improved recognition tracks,
- before/after mitigation comparisons.

## Ethical Note

This is a research and education prototype. It should not be used for surveillance, identity decisions, or production biometric screening. LFW is a public research benchmark and should be handled under research-use expectations.
